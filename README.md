# Machine Learning

Coursework for ELEN 4720: Machine Learning for Signals, Information and Data.

- `hw1/`: Poisson estimation, ridge regression, and polynomial regression.
- `hw2/`: Poisson naive Bayes, logistic regression, and bootstrap AdaBoost.

The folders include Python source, supplied data, computed results, PDF write-ups, and editable LaTeX sources. Temporary files and caches are excluded.

For Homework 2, install the packages in `hw2/requirements.txt`, then run `python hw2/homework2.py`. See `hw2/README.md` for details.
