# ELEN 4720 Homework 2

Submission files:

- `output/pdf/ELEN4720_HW2_solutions.pdf`: written derivations, both cumulative
  confusion matrices, accuracy values, and all seven requested figures.
- `homework2.py`: one original Python source file implementing Problems 2 and 3.

Run `python homework2.py` after installing NumPy, SciPy, and Matplotlib.
The extracted input files must remain in `data/Bayes_classifier/` and `data/boosting/`.
All numerical results and plots are written to `results/`.

The email experiments use the same seeded, random ten-fold partition; each
observation is held out exactly once. The input features are not rescaled.
The logistic algorithms run all 1,000 steepest-ascent and 100 Newton iterations.
AdaBoost runs all 2,500 rounds, sampling 1,000 observations with replacement
from the current distribution in each round.

The editable LaTeX project is `output/latex/`, with `main.tex` and the `figures/`
directory. The figures are copies of those generated by `homework2.py`.
After changing and rerunning the numerical code, copy the new figures from
`results/` into `output/latex/figures/` before recompiling the report.

No title/date, boxed equations, lecture/page references, TikZ plots, or
reproducibility section are included in the written report.

Submit the PDF and Python file separately; the assignment disallows notebooks
and ZIP submissions. The LaTeX source and extracted data are provided for editing
and running the solution, rather than as additional required submission files.
