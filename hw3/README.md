# Homework 3

Submit these two files separately:

- `output/pdf/ELEN4720_HW3_solutions.pdf`
- `homework3.py`

The code uses the extracted files in `data/hw3-data/`. Install NumPy, SciPy,
and Matplotlib, then run `python homework3.py` to reproduce both problems.
Use `--problem 1` or `--problem 2` to run just one problem.

Problem 1 performs ten independent initializations and 100 complete alternating
MAP iterations per run. It saves the full log joint likelihood, the objective
without fixed normalizing constants, sorted final results, test predictions,
the highest-training-objective model, and movie neighbors in `results/`.
Ratings remain on the provided centered scale and are not rounded.

Problem 2 parses the news counts into a 3012 by 8447 sparse matrix. It performs
100 sequential multiplicative updates at rank 25, minimizing the generalized
KL divergence including the contribution of zero-count entries. It saves the
objective trajectory, normalized factors, and all 250 top-word/weight pairs.

The editable LaTeX project is `output/latex/`, including `main.tex` and
`figures/`. `build_report.py` builds it from the numerical results. The PDF uses
the images generated by the code, with no TikZ plots, title/date, boxed
equations, lecture/page references, or reproducibility section.

Do not submit notebooks or a ZIP archive. The assignment requires the PDF and
original numerical source code; the LaTeX project is included for editing.
